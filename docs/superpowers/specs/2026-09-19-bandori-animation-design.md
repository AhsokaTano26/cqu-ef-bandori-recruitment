# 乐队登场秀 `/show` — 设计文档

日期：2026-09-19

## 目标

用 `public/bandori/` 里已下载的 12 支乐队 logo 与 60 个角色立绘，做一个
"Live 开场报幕"式的全屏登场动画，独立成页 `/show`，主页加一个入口进去。

## 已确认的决策

| 项 | 决定 | 理由 |
|---|---|---|
| 核心体验 | 立绘登场秀（非互动图鉴、非音游） | 素材是静态立绘，无音频 |
| 位置 | 独立页 `/show` | 主页已有自动播放入场动画，独立页避免两个全屏动画连播 |
| 角色名 | 立绘入场时同时打出角色名 + 乐队名 | 信息量最足，像 Live 报幕 |
| 编排方式 | 时间轴编排（非物理/粒子） | 报幕需要可预测的节奏与定格；物理随机感会破坏仪式感 |
| 阵容排布 | 一字排开、正面亮相、错升入场 | 最像全员定格 |
| 定格时长 | 2.1s（用户确认 1.2s 也接受，此处取原案） | — |

## 素材现状（实现前提）

- `public/bandori/characters/{乐队}/{文件}.webp` — 235 张，23.3 MB
- `public/bandori/logos/{乐队}.webp` — 12 张，0.6 MB
- 命名两种：旧官网 `{角色}_s{季节}_{序号}`，新官网 `{角色}_{序号}`
- 元数据（角色名、乐队名）**尚未进入仓库**，需新建

**取图规则已实测验证**：优先 `{角色}_s3_1` → `{角色}_1` → `{角色}_s2_1` →
字典序首张。逐角色核对 **60/60 全部命中首选，无降级分支**。
每支乐队恰好 5 人，全员有图。

### 角色名数据来源

已从官方站点页面标题抓取 60 个角色的日文名，并与 Bestdori API 交叉验证
（该 API 覆盖其中 33 个，**日文名全部一致**）。Ave Mujica 五人另有舞台名
（如 豊川祥子 → オブリビオニス），一并记录。

## 动画编排

每支乐队 **6.8 秒**，12 队循环一轮约 82 秒。

| 时间 | 动作 |
|---|---|
| 0–0.6s | 舞台灯光亮起并渐变为该队主题色；logo 从模糊放大定格，带一次冲击波 |
| 0.6–1.8s | 5 张立绘错升入场（中心先起向两侧扩散，间隔 0.09s），从下方 110% 滑入 + 淡出到清晰 |
| 1.8–2.4s | 底部名字牌依次点亮，每张牌用该角色专属色描边；名字逐字打出 |
| 2.4–4.5s | 定格，呼吸式微缩放 1.00 → 1.02 → 1.00 |
| 4.5–5.4s | 整队淡出 + 轻微上移 |
| 5.4–6.8s | 空场，logo 淡出，准备下一队 |

### 配色策略

- **角色名条** 用该角色的官方专属色（Bestdori `colorCode`，数据准确）
- **舞台灯光** 用乐队标识色。注意**乐队色 ≠ 队长色**：Roselia 队长湊友希那
  是红色 `#DD2200`，但 Roselia 的视觉标识是蓝色。故乐队色单独定义。

|---|---|---|

| Afterglow | `#EE0022` | 视觉标识 |
| Hello, Happy World! | `#FFEE22` | 视觉标识 |
| Pastel＊Palettes | `#55DDEE` | 视觉标识 |
| Roselia | `#2A5FD6` | 视觉标识 |
| Morfonica | `#37A9E0` | logo 取色 |
| RAISE A SUILEN | `#4D76CB` | logo 取色 |
| MyGO!!!!! | `#38B1DF` | logo 取色 |
| Ave Mujica | `#EE298B` | logo 取色 |
| 夢限大みゅーたいぷ | `#CB4D7D` | logo 取色 |
| millsage | `#7B4DCB` | logo 取色 |

后 5 支乐队官方未提供色值，从 logo 文件提取主色后归一化到舞台可用亮度
（HLS 的 L 固定 0.55，S 下限 0.55）。提取方法：缩放到 120px 宽，滤掉
低饱和与过暗/过亮像素后取均值。**这几支在实现时需实机目视确认**——
尤其 Morfonica / MyGO / RAISE A SUILEN 三支提取结果都偏蓝，同屏连续
出现时区分度可能不足，必要时手动调整。

## 性能与加载

- 首屏只加载当前 1 队（5 张，约 550 KB）
- 首屏渲染后用 `requestIdleCallback` 后台并发 4 路预载其余 55 张
- 主时钟用 React state 驱动 CSS 动画，**无动画库依赖**（与现有纯 CSS 体系一致）
- `prefers-reduced-motion` 跳过动画，静态展示阵容
- 图片 `decoding="async"`，容器固定尺寸避免 CLS

## 响应式

- **桌面**：5 人一字排开，每人约 15% 视口宽，底部名条
- **手机**：5 人横排超宽，横向拖动卷动画卷（每屏约 2.5 人），入场动画照常播放

## 代码结构

```
app/show/
  page.tsx              服务端组件，导出 metadata
  show-stage.tsx        "use client" — 舞台 + 控制条 + 状态机
  stage.css             动画（沿用现有 keyframes 命名风格）
app/bandori-roster.ts   12 队 + 60 角色元数据（纯数据，无依赖）
```

`/show` 交互：返回主页、暂停/播放、上一队/下一队、队伍直选、速度 0.5×/1×/2×。

主页改动：hero 区新增 `[▶ 观看乐队登场]` 按钮跳转 `/show`，复用现有 `.cta`
的 neo-brutalist 样式。

## 明确不做（YAGNI）

- 不做背景音乐/音效（仓库无音频素材）
- 不做角色详情页、不做图鉴检索
- 不做 235 张全季节造型切换（阵容只用最新造型；素材仍在仓库，后续要做不阻塞）
- 不做服务端渲染动画（纯客户端）

## 验收标准

1. `/show` 可独立访问，首屏不加载全部 23 MB
2. 12 支乐队循环播放，节奏与上表一致
3. 每队 5 人立绘 + 角色名 + 乐队名齐全，日文名与官方一致
4. 暂停/切换/调速/直选均可用
5. 手机端可横向卷动画卷，动画正常
6. `prefers-reduced-motion` 下不播放动画
7. `npm run build` 通过，无新增运行时依赖
